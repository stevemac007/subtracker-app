# SubTracker App Store Wrapping - Requirements

- Technical:
- Wrapper stack: Capacitor with iOS/Android targets.
- Build artifacts: ensure SPA output is produced and accessible from native wrappers.
- Data: offline-first persistence in the wrapper environment with parity to the current SPA.

- Non-technical:
- App Store/Play Store policy alignment (privacy, data storage, usage disclosures).
- Branding: consistent SubTracker visuals and app metadata across wrappers.
- Timeline: define MVP delivery window for wrapper prototype.
